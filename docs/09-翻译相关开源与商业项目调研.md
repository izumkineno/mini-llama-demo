关键技术细节补充：

- **CTranslate2 加速实测**（官方 README benchmark，CPU c5.2xlarge / GPU g5.xlarge A10G）：
  CPU 上 OPUS-MT Transformers 147 tok/s → CT2 525（+int8 696）；GPU 上 1022 → 5876（+fp16 9296），
  内存降 3–4x，BLEU 基本无损（27.90→27.90/27.65）。【已验证】
  结论：NLLB/M2M/OPUS-MT 生产化几乎必经 CT2。
- **fairseq 已归档**：owner 于 2026-03-20 设为 read-only，最后提交 2025-09-30【已验证二手】；
  OpenNMT-py 于 2024-07-04 转 maintenance mode，官方喊话换 Eole【已验证论坛帖】。
  新项目训练侧选 Eole / fairseq2（成熟度待验），推理侧选 CT2 / Marian。
- **pivot 中转**：Argos 无直接模型对时经中间语言（如 es→en→fr），质量衰减，README 自述有 loss。【已验证】
- **NLLB 使用红线**：model card 明确 not for production、不做认证翻译、输入 >512 tokens 质量降、
  通用域非医疗法律。【已验证】
- **M2M100 vs NLLB 商用**：NLLB-NC 禁商用已定；M2M100 疑可商用，是"多语互译+可商用"的首选，
  但必须先核对 HF model card License 栏。【推断】

### 3.3 架构对比：端到端 vs 级联

| 路线 | 代表 | 延迟特征 | 质量 / 可控 | 商用友好度 |
|---|---|---|---|---|
| 端到端 S2S（直建模） | SeamlessStreaming(EMMA)、GPT Realtime、SPARK S2S、Pixel Voice Translate | 最低（连续流，无等待整句；AL 1–2s 级） | 韵律/音色保持好；可解释/可干预差 | 差（Seamless NC；GPT 按量贵；Pixel 无 API） |
| 直接 S2T+TTS（两遍） | UnitY/UnitY2、ESPnet-ST S2S | 中（等文本再合成） | 平衡；文本可审校 | 中（自训 + Apache 组件可商用） |
| 级联 STT+MT+TTS | WhisperLiveKit、LiveKit Agents、Azure 经典、DeepL Voice、RSI 三家 | 最高（三段串行 + 标点等待；优化后 E2E 0.8–2.5s） | 每段可换/可审/可计费；错误累积 | **最好**（MIT/Apache 组件 + 云 API） |
| 异步配音 | ElevenLabs、Rask | 分钟级 | 质量最高（可人工修） | 好（按量付费） |

流式策略演进【已验证】：固定 wait-k（fairseq 基线）→ 自适应（CTC 分词 / AlignAtt / EMMA，
按"信息足够否"动态读/写）→ 连续流原生 S2S（GPT Realtime Translate，无显式 chunk）。
评测口径：SimulEval（AL/APAL/DAL + BLEU），IWSLT 计算感知/非感知双报；
低/中/高延迟档 AL ≤1000/2000/4000ms。综述见 [arXiv:2406.00497](https://arxiv.org/html/2406.00497v2)。

### 4.3 字幕技术横评（流程视角）

- **ASR 底座**：开源几乎全收敛到 Whisper 系（openai-whisper MIT → faster-whisper CT2 →
  XXL 发行 → Buzz 桌面）；VideoLingo 分出 Qwen3-ASR 新分支；Seamless 另起 M4T 线但 NC 禁商用。
- **断句**：whisper 原生按 30s 窗+标点粗切；VideoLingo NLP+LLM 按长度/语义重切（最优）；
  stable-ts 按 punct/gap regroup；SubtitleEdit 按 CPS/时长 QC。
- **对齐三路线**：(1) wav2vec2/Qwen3 phoneme forced alignment（WhisperX/Qwen3-ForcedAligner，
  最准，需语种模型，中日特殊）；(2) whisper cross-attention+DTW+VAD 修正（stable-ts/faster-whisper，
  通用免语种模型）；(3) 人工波形（Aegisub/SE）与云黑盒（商业）。
- **MT**：传统 NMT（Google/DeepL）vs LLM 批译（行级保时间戳 + glossary + reflection；
  Cerlancism timestamp 模式可合并条目，VideoLingo 术语+反思）。
- **压制/烧录**：`ffmpeg subtitles=` 滤镜为事实标准；ass 特效靠 Aegisub/SE；
  双语 srt 合并 / ass 多行样式；弹幕 biliass/DanmakuFactory xml→ass。
- **说话人**：pyannote diarization 为主（WhisperX/XXL/Buzz），词级分配仍不完美；
  VideoLingo 明确不支持自动多音色；商业靠云 diarization+人工。
- **双语/术语**：开源 VideoLingo + translate-subtitles 最完整；
  商业 HeyGen/Maestra/Rask 以配音+lip-sync 见长。

建议 PoC 链：yt-dlp → WhisperX 或 VideoLingo（Qwen3）→ Cerlancism/translate-subtitles 术语批译 →
SubtitleEdit QC → ffmpeg 烧录；长片加 stable-ts `adjust_gaps()`；B 站加 biliass 弹幕轨。
